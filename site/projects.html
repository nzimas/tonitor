Other projects

Other firmware and instruments by Nuno Zimas, for the FM-1 and for other hardware. The source code of each is on GitHub.

Bigorna

M-VAVE FM-1

Firmware for rhythmic noise, power noise, power electronics and IDM, with the Elektron Digitone II as its reference. Six tracks, four machines (4-OP, DRUM, WAVY and HIVE), a 16-step sequencer with parameter locks and trig conditions, a sound generator and a phrase generator. Installed from the browser, over USB MIDI.

Website GitHub repository

Norilsk

M-VAVE FM-1

Firmware for dark ambient, harsh drones and noise. Three generators, each drawn at random and routed through its own chain of effects drawn at random, into a master delay and plate reverb. Installed from the browser, over USB MIDI.

Website GitHub repository

Tonitor for the SMK-37 Pro

M-VAVE SMK-37 Pro

Tonitor for the M-VAVE SMK-37 Pro keyboard: six tracks, eight synthesis engines, loopers and sequencers. It shares its sound engines with Tonitor for the FM-1; the panel, the manual and the builds are its own.

Website GitHub repository

SteamRoller

Novation Circuit Rhythm

Firmware for rhythmic noise, IDM and experimental percussion. It keeps the Circuit Rhythm's own functions and adds a drum sound generator that stores its sounds as samples in the pack, Elektron-style parameter locks, and the Grid FX locked to single steps of single tracks.

Website GitHub repository

Motor:Cycles

Elektron Model:Cycles

Firmware for rhythmic noise and power noise. Generative algorithms build sounds, kits, phrases and patterns, with one control for how complex and dense the result is; the Model:Cycles' own functions stay available. Based on the official OS 1.13 and installed with a browser patcher that modifies your own copy of the official firmware.

Website GitHub repository

DigiRust

Elektron Digitone II

Firmware tools for IDM, rhythmic noise and power noise, and electroacoustic music: a browser patcher and a macOS app that create a modified copy of the official Digitone II OS on your computer. No Elektron firmware is distributed. For the Digitone II only.

Website GitHub repository

PoundHard

Ableton Move

A 16-track groovebox for IDM, rhythmic noise and percussion-based experimental electronic music. A SuperCollider engine does the sound, a Python controller holds the musical state, and the Move's pads, buttons, encoders and screen are the interface. Two editions:

  • Armbian editionCurrent

    Runs on Armbian with a real-time kernel, in place of Ableton's software; started from a menu on the Move's screen.

    GitHub repository
  • Schwung editionNo longer updated

    Runs alongside the Move's own software, as a Schwung takeover module.

    GitHub repository

Granola

macOS · Ableton Move · Akai MPC One

A multitrack granular synthesizer: each track reads a sample as material for grain clouds around a playhead moved by hand. Three versions, for different hardware:

  • Granola for macOS

    Eight tracks, played from the M-VAVE SMC-Mixer and SMC-Pad Pocket. SuperCollider's audio server is built into the app; 154 Airwindows effects, reverb and delay.

    Downloads GitHub repository
  • Granola for Move

    Eight tracks on the Ableton Move, as a Schwung takeover module, with the macOS version's sound engine. Includes a sample harvester.

    GitHub repository
  • Granola MPC

    Five tracks on the Akai MPC One (first generation), on the OpenMPC environment in place of the stock application. Filters, nine LFOs per track, parameter-lock pads and gesture loops.

    GitHub repository
