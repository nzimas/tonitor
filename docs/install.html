Install Tonitor

This page installs Tonitor on an M-VAVE FM-1 connected to this computer, over USB MIDI. It works in a desktop Chrome, Edge or Opera. It talks to the FM-1 directly: nothing is uploaded anywhere.

Read this first

Tonitor is an unofficial firmware, not made, endorsed or supported by M-VAVE. Installing it replaces the FM-1's firmware and may void any warranty that applies to your device. An interrupted update can leave the FM-1 unable to start until it is recovered. Saving Tonitor sessions overwrites any SLOOP projects on the device. The software comes with no warranty of any kind; you install it entirely at your own risk. Full disclaimer.

Before you start

  1. Use a USB cable that carries data (some carry power only), plugged straight into the computer.
  2. Switch the FM-1 on, and close any other program using MIDI (a DAW, M-VAVE's app).
  3. When the browser asks to let this page control MIDI devices, allow it: the update is sent as MIDI system-exclusive messages.

If something goes wrong

Stopped part-way? Reload this page and install again: an FM-1 left in update mode is found and the write is finished. If the FM-1 does not start, hold OCT− while switching it on: the screen says RESCUE, and the install can be run again. Two failed starts in a row also enter rescue mode. If it no longer starts at all, recovery needs FM-1-transporter.

Prefer the command line? Build and install from source.

The installer (js/fm1ota.js) is a port of Felucca and SLOOP's installer, GPL-3.0; the firmware it installs is GPL-3.0, its source on GitHub.
